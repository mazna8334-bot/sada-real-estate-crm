# تطبيق سادة التطوير للعقارات - النسخة الأولى

## التشغيل
1. ثبّت Python 3.
2. داخل مجلد المشروع نفّذ:
   pip install -r requirements.txt
3. ثم:
   python app.py
4. افتح المتصفح على:
   http://127.0.0.1:5000
